# 袋鼠君独立站 🦘

在 Rakuten / Amazon JP 卖 Italian Brainrot IP 周边商品的独立站。

## 技术栈

Next.js 14 · TypeScript · Tailwind CSS · Stripe · PayPal · Vercel

## 快速链接

- 线上地址：https://kangaroo-shop-orpin.vercel.app
- 项目状态：→ [STATE.md](STATE.md)
- 详细进展：→ [docs/progress.md](docs/progress.md)
- 部署指南：→ [DEPLOY.md](DEPLOY.md)

## 本地开发

```bash
pnpm install
pnpm dev
```

打开 http://localhost:3000

## 规范

- 所有项目状态变更 → 直接修改 `STATE.md`
- 详细开发过程 → 写入 `docs/progress.md`
- 禁止在 README 里写状态（状态只认 STATE.md）
