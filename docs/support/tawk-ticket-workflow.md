# kangaroo-shop 客服工单与 tawk.to 预聊天表单配置

## 目标

让客户进线前先留下最小必要信息，客服接线后能快速建单、查单、分流，并把高风险售后交给负责人确认。

## tawk.to 预聊天表单建议字段

1. 姓名或称呼
   - 类型：文本
   - 必填：否
   - 用途：客服称呼客户

2. 邮箱
   - 类型：邮箱
   - 必填：是
   - 用途：用于查单和后续联系
   - 注意：后台页面只展示脱敏邮箱，回复客户时不要完整复制后台信息

3. 订单号
   - 类型：文本
   - 必填：否
   - 示例：KS20260510001
   - 用途：有订单号时优先按订单号查单

4. 问题类型
   - 类型：下拉单选
   - 必填：是
   - 选项：订单查询、支付问题、物流问题、退款/售后、商品咨询、其他

5. 问题描述
   - 类型：多行文本
   - 必填：是
   - 提示文案：请描述您遇到的问题。请不要发送银行卡号、密码、完整证件号等敏感信息。

## tawk.to 标签建议

- order_lookup：订单查询
- payment_check：支付核对
- shipping_check：物流查询
- refund_escalation：退款/售后升级
- product_question：商品咨询
- privacy_sensitive：客户发送了敏感信息，需要提醒删除或停止传播
- needs_owner_review：需要花哥或负责人确认

## 工单台账字段

1. 工单编号
2. 创建时间
3. 来源：tawk.to / 邮件 / 其他
4. 客户语言
5. 客户称呼
6. 脱敏邮箱
7. 订单号
8. 问题类型
9. 当前状态：新建 / 处理中 / 等客户回复 / 已升级 / 已解决 / 已关闭
10. 优先级：普通 / 高 / 紧急
11. 客服处理动作
12. 是否升级
13. 升级原因
14. 下一步跟进时间
15. 负责人
16. 备注

## 标准处理流程

1. 建单
   - 收到咨询后记录来源、问题类型、订单号或邮箱。
   - 不记录银行卡号、密码、完整地址截图等敏感信息。

2. 查单
   - 进入 `/admin/support` 客服工作台。
   - 用订单号或邮箱查询。
   - 只查看订单状态、商品摘要、配送方式和脱敏联系方式。

3. 回复
   - 使用客服工作台内置模板。
   - 只回复客户解决问题所需的信息。
   - 不复制完整邮箱、手机号、地址、支付流水。

4. 升级
   - 退款、赔偿、补发、改地址、支付争议统一升级。
   - 客服不得直接承诺退款、赔偿、补发或改地址。

5. 回填
   - 每次回复后更新台账状态、处理动作、下一步跟进时间。

## 安全红线

- 不在 tawk.to 自动传入订单号、邮箱、手机、地址、支付流水。
- 不在客服台账中保存完整支付敏感信息。
- 不把 `/admin` 后台页面暴露给非管理员。
- 不通过聊天窗口承诺退款、赔偿、补发、改地址。
- 没有物流单号或到达日时，必须说明正在核实，不能编造。
