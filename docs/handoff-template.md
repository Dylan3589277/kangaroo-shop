# Handoff 交接模板

用于一个 agent 把任务交给另一个 agent，或长会话中断后恢复。

## 项目

kangaroo-shop 袋鼠君跨境电商站

## 目标

本阶段要完成什么。

## 已确认事实

1. 项目边界、业务规则、关键文件。
2. 经过验证的事实，不写猜测。

## 已做操作

列出已经读取、修改、运行过的内容。

## 产物路径

文件、提交、PR、日志、截图或报告路径。

## 验证结果

运行过的命令、测试、脚本、浏览器检查，以及结果。

## 未解决问题

还缺什么信息、权限、日志或确认。

## 下一个 agent 建议

应该加载什么 skill、走什么流程。

## 不要重复做的事

避免浪费和覆盖已有结果。

## 项目边界提醒

不能使用 daishujundulizhan 数据库；该数据库属于 kangaroo-japan 日本代拍独立站。kangaroo-shop 使用 Vercel Storage 的 kangaroo-shop 库。
