2. 业务方向：从中国进口/采购商品，卖往全球。
3. 主要目标市场：日本、欧美。
4. 网站语言：根据用户 IP 自动切换语言显示。
5. 品牌视觉：根据花哥提供的 logo 图片适配网站，并按 logo 主色重新设计网站配色。
6. UI 风格：简洁、高端，符合日本及欧美审美。
7. 平台运营能力：一键导入多平台产品、一键上架多平台产品，功能要真正落实。

## 执行拆分

### A. 定位与国际化

目标：让 kangaroo-shop 明确成为“中国采购 → 全球销售”的跨境电商站。

任务：
- 首页、商品页、后台文案去掉容易误解成日本代拍的表达。
- 保留日文、中文、英文三语言。
- 根据 IP/国家地区自动选择语言：
  - 日本 IP 默认日文。
  - 中国大陆/港澳台中文优先。
  - 其他欧美地区英文优先。
  - 允许用户手动切换语言，手动选择优先于 IP 自动判断。

### B. Logo 与网站视觉升级

目标：根据 logo 颜色建立统一品牌配色，UI 简洁高端。

等待材料：
- 花哥需要补发 logo 图片。

初步方向：
- 页面留白更大。
- 色彩控制在 1 个主色、1 个辅助色、黑白灰中性色。
- 减少杂乱渐变和强促销风格。
- 商品卡片、导航、按钮统一圆角和阴影层级。
- 同时兼容日本审美的干净秩序感，以及欧美审美的品牌感。

### C. 多平台产品导入

目标：运营后台可以把外部平台商品导入为 kangaroo-shop 商品草稿。

已完成 P0 地基：
- `/[locale]/admin/import` 页面。
- `/api/admin/import/*` 导入接口。
- `sync_jobs`、`sync_job_items`、`product_platform_listings`、`product_variants` 表。
- 支持 CSV/TSV 解析的基础结构。

下一步落实：
- 乐天 RMS CSV 导入：商品编号、SKU、标题、价格、库存、图片、分类、描述。
- Amazon Seller Central 报表导入：SKU、ASIN、标题、价格、库存、图片链接。
- 导入后默认进入“草稿/待审核”，不直接公开，避免数据污染。
- 导入结果需要后台可查看：成功、跳过、错误行、错误原因。

### D. 多平台一键上架

目标：后台审核后，可以把商品发布到多个平台。

分阶段落实：
- P1：一键发布到自建站 kangaroo-shop，即商品从草稿变为上架。
- P2：生成乐天 RMS 可上传 CSV，由人工上传，降低平台 API 风险。
- P3：生成 Amazon 上架/报价模板或接入 SP-API 的只读/草稿能力。
- P4：接入乐天 RMS API、Amazon SP-API，做真正 API 自动上架。

安全边界：
- 不在代码中保存任何平台密钥。
- 不把未审核商品自动上架到外部平台。
- 所有外部平台写操作必须有预览、确认、日志和失败重试。
- 真正调用乐天/Amazon 写接口前，需要花哥明确授权并提供正式 API 权限。
